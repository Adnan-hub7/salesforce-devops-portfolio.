# Salesforce DevOps Portfolio Projects

Illustrative learning/sample repository demonstrating Salesforce DevOps workflows. These examples are for portfolio demonstration and should not be represented as production deployments.

## Included examples
- Azure DevOps YAML validation pipeline
- GitHub Actions validation workflow
- Jenkins pipeline
- Salesforce CLI validation and deployment scripts
- Salesforce package manifest
- Architecture, branching, and release checklist documentation

## Repository structure
```text
.github/workflows/salesforce-validation.yml
docs/architecture.md
docs/branching-strategy.md
docs/release-checklist.md
manifest/package.xml
scripts/deploy.sh
scripts/validate.sh
azure-pipelines.yml
Jenkinsfile
```

## Before using
Replace sample org aliases, authentication references, and environment-specific settings with your own Salesforce Dev Hub / org configuration. Never commit passwords, tokens, private keys, or org credentials.
